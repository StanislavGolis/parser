================================================================================
## 1. ОБЩАЯ КОНЦЕПЦИЯ
================================================================================

Сайт представляет собой тёмный, «технический» интерфейс, напоминающий смесь
закрытого архива, файлового менеджера и галереи. Без глянца, с акцентом на
«сырость» данных. Минималистичный, плоский дизайн без теней и градиентов.

Ключевые принципы:
- Моноширинные шрифты для всех технических данных (размеры, хеши, счётчики).
- Плоские цвета, тонкие рамки, никаких скруглений больше 4px.
- Атмосфера «закрытого архива»: статусы, метаданные, маркировка премиум-доступа.
- Отсутствие светлой темы — только тёмная.

## 4. КЛЮЧЕВЫЕ UI-ЭЛЕМЕНТЫ
================================================================================

### 4.0. Главная — витрина новинок (`/`)

Главная встречает медиа, а не списком разделов: каталог живёт на `/boards`,
полный поток — на `/new`.

Состав сверху вниз:
1. **Сводка архива** (2 строки, без баннера): слева `архив // новое`, справа
   моном цифры — `файлов · тредов · +N за сутки`. Служебного состояния парсера на
   публичной странице нет.
2. **«Новое с прошлого визита»** (появляется только при новинках): компактный блок
   `+57 новых файлов с 12 сентября →` — ссылка на `/new?since=<момент визита>`.
   Момент визита хранится в cookie `dv_last` (год), ставится клиентом, читается на
   сервере.
3. **Чипы фильтра**: `ВСЁ / КАРТИНКИ / ВИДЕО` + `без подписки`. Фильтр пишется в
   URL (`?type=`, `?free=1`), фильтрует сервер — ссылкой можно делиться.
4. **Masonry-сетка**: ровно **24 карточки**, без автоподгрузки; под сеткой —
   «показано N из M» и кнопка «Смотреть дальше в полном потоке →» (`/new`).
5. **Полка «Популярное сейчас»** — 6 карточек (`/api/v1/top?period=week`), со своим
   лайтбоксом; справа ссылка «весь топ →».
6. **Чипы разделов** — `/v 1 234`, `/aa 980`, … (клик → раздел) + «все разделы →» (`/boards`).

Правила:
- Над сеткой — не больше ~100 px контента: медиа должно попадать в первый экран.
- Сетка не «прыгает»: фиксированные пропорции карточек + `thumb_blur` как фон
  (blur-up: размытая подложка → проявление превью), первые 6 карточек грузятся
  сразу (`eager` + `fetchpriority=high`).
- Автоплей видео/гифок в сетке запрещён; просмотр — в лайтбоксе (`←`/`→`, свайпы).
- Карточек фиксированное число — бесконечная лента живёт только на `/new`.

### 4.4. Карточка медиа (Masonry Grid)
Структура:
  [Превью (фото или видео)]
  [Строка метаданных]

Превью:
  - Фон: --bg-secondary
  - Рамка: 1px --border
  - Ховер: рамка --accent-primary
  - Для видео: тёмный оверлей с иконкой Play и длительностью (например, «▶ 0:42»)
  - Длительность: моноширинный, 12px, белый на полупрозрачном чёрном фоне

Строка метаданных:
  Формат: /b/ • 2.4 МБ • 1080×720 • 1.2к
  Шрифт: JetBrains Mono, 11px, --text-muted
  Иконки: если есть (замок/звезда для премиума, звезда для топа) — 12px

Действия поверх превью:
  - Правый верхний угол: [🏷 метка + счётчик] — компактная кнопка на полупрозрачной
    подложке (bg-black/60, backdrop-blur), активное состояние — --accent-primary;
  - Левый верхний угол: бейджи 🔒/★ `PREMIUM` (см. 4.6) или [ТОП];
  - Правый нижний угол: для видео — значок ▶ и длительность (`0:42`);
  - Клик по действию не открывает lightbox (stopPropagation);
  - Для анонима действие видно, но по клику предлагает войти (метка требует аккаунт).

Загрузка превью (blur-up):
  - Пока грузится `thumb`, под ним лежит размытый вариант (`blur_url`, поле
    `thumb_blur`) — плитка сразу «цветная», без пустых прямоугольников;
  - Если размытого варианта нет — пульсирующий скелетон (--bg-tertiary);
  - Превью проявляется поверх подложки (opacity 300 мс), пропорции заданы заранее
    (`aspect-ratio`), поэтому сетка не смещается;
  - Готовность превью определяется не только событием `load`: при монтировании и
    смене файла проверяется `complete` (картинка из кэша события не даёт), плюс
    страховочный таймаут — «зависший» блюр без превью невозможен.

Состояние метки:
  - Метка «отличный контент» — это персональный флаг: он приходит с API (`marked`)
    и **всегда подсвечен оранжевым** у того, кто её поставил (в том числе после
    перезагрузки страницы);
  - Снятие метки — повторный клик (и пробел в лайтбоксе).

### 4.4b. Каталог разделов (`/boards`)
Карточка раздела — не текстовая плитка, а **мозаика 2×2** из четырёх свежих
превью раздела (`cover_thumbs` в `/api/v1/boards`). Карточка компактная: раздел
должен читаться как раздел, а не как файл.
  - Мозаика: пропорции 2:1 (невысокая полоса), между плитками 1px --border;
  - Пока плитка грузится — пульсирующий скелетон, затем проявление превью
    (готовность проверяется по `complete` + таймаут — плитка не «зависает»);
  - Пустые плитки (в разделе меньше четырёх файлов) — приглушённая подложка;
  - Подпись: моном-метка `раздел` + `/<slug>` (Foreground), ниже — название
    раздела и `N файлов`; у премиум-раздела бейдж 🔒/★ и «по подписке»,
    у обычного — «открыть →» на ховере;
  - Закрытый премиум-раздел отдаёт только размытые варианты плиток;
  - Сетка: 1 / 2 / 3 / 4 колонки (mobile / sm / lg / xl), ховер — рамка
    --accent-primary; плитки первых двух карточек грузятся сразу (LCP).

    «Метка поставлена · 42» / «Метка снята» (1.4 с);
  - Esc — закрыть; клик по фону — закрыть.

### 4.6. Премиум-контент (замок/звезда, размытые превью + CTA)
Список/плитка:
  - Премиум и подписки нет (`locked=true`): превью — то же изображение
    (`thumb_blur`) с CSS-блюром (blur 7–8px, лёгкий scale 1.1), поверх —
    затемнение 35 % и бейдж 🔒 `PREMIUM` (--accent-warning, тултип
    «Премиум-контент: нужна подписка»);
  - Премиум и подписка активна (`is_premium && !locked`): блюра нет, бейдж
    ★ `PREMIUM` (та же рамка/цвет, тултип «Премиум-контент: доступен по вашей
    подписке») — чтобы было видно, где премиум, но без сигнала «закрыто»;
  - У закрытого видео вместо кнопки Play — только размытый постер и замок.

Карточка раздела («Мои разделы»):
  Строка 1: #позиция · /slug · название (переименование) · статистика
  Строка 2: кнопка «Треды ▾» · тумблер «Парсить» · «published | unpublished» ·
            «FREE | PREMIUM» · ▲/▼ очередь · удалить
  Статистика: В БД / В S3 / Скачано / Пропущено / В каталоге / Видимых
  (дубли-ссылки не считаются — числа совпадают с сайтом).
  Прогресс парсера: полоса + «парсим тред №X: N/M файлов», «обновлено N с назад»,
  при простое >60 с — красная полоса и «возможно завис».

Треды раздела (аккордеон):
  Чипы: Все · В работе · Парсить · published · PREMIUM · В очереди · Недокачано · Просроченные · Мёртвые · Без настроек
  Поиск по теме/номеру; «в работе» сверху; массовые кнопки:
  Парсить вкл/выкл · Показать/Скрыть · PREMIUM вкл/выкл · Вернуть в обход · В очередь.
  В строке треда: файлов (files_detected) / скачано (уникальных) / в хранилище /
  видимых / постов / просмотров · тумблеры Парсить / published / PREMIUM
  (при премиум-доске доски тумблер заблокирован с пометкой «унаследовано от доски»).
  Итог последнего прохода: мелкий моноширинный текст «итог скана: новых N, уже было …»
  (у треда с ошибками — --accent-warning), в подсказке — время и «обработано по пост #N».
  Плашки состояния: «просрочен» (парсинг включён, но тред давно не сканировался) —
  текст/рамка --accent-warning; «нет в каталоге» с датой исчезновения и числом
  промахов + кнопка «вернуть в обход» — --accent-danger. Бейдж «очередь: причина»
  --accent-secondary — тред ждёт докачки (фаза B двухфазного цикла).

Тумблеры (переключатели):
  Вкл: фон --accent-secondary, кружок #0A0C0F
  Выкл: фон --bg-tertiary, кружок --text-muted
  Заблокирован (наследование): opacity 60 %, cursor not-allowed

Кнопки действий: малая кнопка (см. 4.3), текст --text-secondary,
  ховер --text-primary; опасные операции (удаление раздела) — --accent-danger.

Глобальные кнопки в шапке админки:
  «Запустить/Остановить парсер» · «Сканировать треды» (в карточке доски) ·
  «Оптимизировать медиа» (бэкфилл, прогресс «осталось N из M») ·
  «Очистить S3» · «Сбросить всё».

## 5. АНИМАЦИИ И ПЕРЕХОДЫ

Длительность: 150–250ms, без плавных затуханий.

Карточки в ленте:

             с задержкой 20ms на карточку (stagger-эффект)

Ховер на карточке:
  Изменение рамки: мгновенное (transition 150ms)

Ховер на кнопках:
  Изменение фона/рамки: transition 150ms

Lightbox:
  Открытие: fade-in (opacity 0 → 1), 200ms
  Закрытие: fade-out (opacity 1 → 0), 150ms

Индикатор загрузки:
  Пульсация: opacity 0.3 ↔ 1.0, цикл 1s, ease-in-out

## 7. ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ
================================================================================

CSS-фреймворк: Tailwind CSS (уже используется в проекте).

Иконки: Lucide Icons (острые, минималистичные), размеры 14–24px.

Шрифты: подключить через Google Fonts или self-host.

Изображения:
  - Превью: WebP, качество 80%, максимальная ширина 400px
  - Полноразмерные: оригинал из S3 через подписанный URL
  - Ленивая загрузка: loading="lazy" для всех изображений

Доступность:
  - Контраст текста минимум 4.5:1 для основного текста
  - Все иконки должны иметь aria-label
  - Кнопки и ссылки — с фокус-стилем (outline 2px --accent-primary)

Производительность:
  - Размер шрифтов: не более 2 файлов (woff2)
  - Первый экран: не более 1 МБ данных
  - Время загрузки: LCP не более 2.5s, CLS не более 0.1

Кроссбраузерность:
  - Chrome, Firefox, Safari, Edge (последние 2 версии)
  - Mobile: Android Chrome, iOS Safari
