================================================================================
## 1. ОБЩАЯ КОНЦЕПЦИЯ
================================================================================

Сайт представляет собой тёмный, «технический» интерфейс, напоминающий смесь
закрытого архива, файлового менеджера и галереи. Без глянца, с акцентом на
«сырость» данных. Минималистичный, плоский дизайн без теней и градиентов.

Ключевые принципы:
- Моноширинные шрифты для всех технических данных (размеры, хеши, счётчики).
- Плоские цвета, тонкие рамки, никаких скруглений больше 4px.
- Атмосфера «закрытого архива»: статусы, метаданные, маркировка премиум-доступа.
- Отсутствие светлой темы — только тёмная.

## 4. КЛЮЧЕВЫЕ UI-ЭЛЕМЕНТЫ
================================================================================

### 4.1. Логотип
Формат: текстовый, без иконки.
Пример:
  DREDGE
архив // отбор // доступ
  архив / галерея / доступ
Стиль: JetBrains Mono Bold, 20px, letter-spacing 0.15em, цвет --text-primary.
Подзаголовок: 11px, --text-muted, lowercase.

### 4.2. Навигация (главное меню)
Элементы: [Доски ▾] [Новинки] [Популярное] [Избранное] [Поиск]
Мобильная нижняя навигация: те же 5 пунктов (иконки: слои, изображение, звезда,
закладка, поиск; сетка 5 колонок).
Стиль:
  - Фон: --bg-primary
  - Пункты: 14px, --text-secondary
  - Активный пункт: --text-primary + нижняя граница 2px --accent-primary
  - Ховер: --text-primary, без фона
  - Выпадающий список «Доски»: фон --bg-secondary, рамка 1px --border,
    пункты --text-secondary, ховер --text-primary

### 4.3. Кнопки
Основная кнопка (например, «Скачать»):
  - Фон: --accent-primary
  - Текст: #0A0C0F (тёмный), 14px, SemiBold
  - Рамка: нет
  - Скругление: 4px
  - Паддинг: 10px 16px
  - Ховер: яркость +10% (filter: brightness(1.1))

Вторичная кнопка:
  - Фон: прозрачный
  - Текст: --text-primary
  - Рамка: 1px --border
  - Ховер: рамка --border-hover, фон --bg-tertiary

Малая кнопка (например, «Загрузить ещё»):
  - Фон: --bg-secondary
  - Текст: --text-secondary
  - Рамка: 1px --border
  - Скругление: 4px
  - Паддинг: 8px 14px
  - Ховер: рамка --border-hover, текст --text-primary

### 4.4. Карточка медиа (Masonry Grid)
Структура:
  [Превью (фото или видео)]
  [Строка метаданных]

Превью:
  - Фон: --bg-secondary
  - Рамка: 1px --border
  - Ховер: рамка --accent-primary
  - Для видео: тёмный оверлей с иконкой Play и длительностью (например, «▶ 0:42»)
  - Длительность: моноширинный, 12px, белый на полупрозрачном чёрном фоне

Строка метаданных:
  Формат: /b/ • 2.4 МБ • 1080×720 • 1.2к
  Шрифт: JetBrains Mono, 11px, --text-muted
  Иконки: если есть (замок/звезда для премиума, звезда для топа) — 12px

Действия поверх превью:
  - Правый верхний угол: [🔖 избранное] [🏷 метка + счётчик] — компактные кнопки
    на полупрозрачной подложке (bg-black/60, backdrop-blur), активное состояние —
    --accent-warning (избранное) и --accent-primary (метка);
  - Левый верхний угол: бейджи 🔒/★ `PREMIUM` (см. 4.6) или [ТОП];
  - Клик по действию не открывает lightbox (stopPropagation);
  - Для анонима действия видны, но по клику предлагают войти (метки и избранное
    требуют аккаунт по матрице ролей).

### 4.5. Lightbox (просмотр файла)
Фон: #050708 (темнее основного фона)
Структура:
  [Кнопка закрытия ×] — правый верхний угол, 24px, --text-secondary,
                         ховер --text-primary
  [Контент] — по центру, максимальная ширина 90vw, максимальная высота 80vh
  [Панель информации] — внизу

Панель информации:
  Строка 1: /b/ • image_2026_01_15.jpg • 2.4 МБ • 1920×1080
  Строка 2: MD5: a1b2c3d4e5f6...  SHA-256: 1234abcd...
  Строка 3: [Кнопка «Скачать»] [Счётчик просмотров] [Счётчик скачиваний]
  Все строки: JetBrains Mono, 12px, --text-secondary
  Действия: [🏷 метка + счётчик] [🔖 в избранное] — активные состояния
            --accent-primary / --accent-warning; требуют аккаунт
  Кнопка «Скачать»: основная кнопка (см. 4.3); для анонима/без подписки — вместо
  неё CTA «Нужна подписка» → /profile
  Счётчики: формат «1.2к просмотров», «340 скачиваний»

Горячие клавиши и колесо (навигация по файлам треда):
  - ← / →  — предыдущий / следующий файл;
  - колесо мыши — то же листание: вниз — следующий, вверх — предыдущий
    (W1: накапливаем дельту до порога 40px и держим кулдаун 300 мс, поэтому
    инерционное колесо/трекпад не проматывает десяток файлов; Ctrl/⌘+колесо
    не перехватываем — это зум браузера; над лентой миниатюр колесо не листает);
  - пробел — метка текущего файла (как кнопка 🏷), с плашкой-подтверждением
    «Метка поставлена · 42» / «Метка снята» (1.4 с);
  - Esc — закрыть; клик по фону — закрыть.

### 4.6. Премиум-контент (замок/звезда, размытые превью + CTA)
Список/плитка:
  - Премиум и подписки нет (`locked=true`): превью — то же изображение
    (`thumb_blur`) с CSS-блюром (blur 7–8px, лёгкий scale 1.1), поверх —
    затемнение 35 % и бейдж 🔒 `PREMIUM` (--accent-warning, тултип
    «Премиум-контент: нужна подписка»);
  - Премиум и подписка активна (`is_premium && !locked`): блюра нет, бейдж
    ★ `PREMIUM` (та же рамка/цвет, тултип «Премиум-контент: доступен по вашей
    подписке») — чтобы было видно, где премиум, но без сигнала «закрыто»;
  - У закрытого видео вместо кнопки Play — только размытый постер и замок.

Lightbox премиум-файла (вместо контента):
  [Иконка замка] (28px, --accent-warning)
  Заголовок: «ПРЕМИУМ-КОНТЕНТ», 11px, uppercase, --accent-warning
  Подпись:  «Файл доступен по премиум-подписке. Активируйте премиум в профиле,
             чтобы смотреть и скачивать полные версии.» (12px, --text-secondary)
  Кнопка:   «Активировать премиум» — primary, ведёт на /profile
  Счётчики и «Скачать» остаются, но вместо кнопки скачивания — кнопка Premium → /profile.

### 4.6b. Профиль и активация премиума (`/profile`)
  Заголовок: «ПРОФИЛЬ», email — моноширинный, 11px, --text-muted
  Карточка статуса (рамка 1px):
    - активен:   рамка/текст --accent-warning, «ПРЕМИУМ АКТИВЕН», «Действует до: <дата>»;
    - не активен: рамка --border, «БЕСПЛАТНЫЙ ДОСТУП», подпись про ограничения;
  Кнопка: «Активировать премиум на 1 день» (primary, на всю ширину карточки),
          рядом подпись мелким: «Пока бесплатно (тестовый период). Повторная
          активация продлевает срок.»
  В шапке сайта: email ведёт в профиль, у премиум-пользователя — префикс «★».
  Ниже карточки статуса — две плитки-счётчика: [🔖 избранное → /favorites] и
  [🏷 метки] (моноширинные числа), под ними подпись-пояснение про метку и избранное.

### 4.6c. Избранное (`/favorites`)
  Заголовок: «ИЗБРАННОЕ // <N файлов>» (моноширинный, uppercase, как другие разделы)
  Контент: та же masonry-галерея, что и в лентах (карточки с действиями и бейджами),
  список: свежие добавления сверху; пустое состояние — «В избранном пусто» с подсказкой
  нажать закладку на карточке.
  Без входа: экран-приглашение «НУЖЕН АККАУНТ» + кнопка «Войти» (метки и избранное
  доступны только аккаунту).

### 4.7. Бейджи и статусы
Форматы:
  [ПРОВЕРЕН]  — фон transparent, рамка 1px --accent-secondary,
                текст --accent-secondary, 10px, uppercase, JetBrains Mono
  [ОЖИДАЕТ]   — рамка 1px --accent-warning, текст --accent-warning
  [АРХИВ]     — рамка 1px --text-muted, текст --text-muted
  [PREMIUM]   — рамка 1px --accent-warning, текст --accent-warning;
                с иконкой замка, если доступа нет (превью размыто), и со звездой,
                если подписка активна (контент открыт)
  [ТОП]       — рамка 1px --accent-primary, текст --accent-primary,
                с иконкой звезды
Паддинг: 2px 6px, скругление 3px.

### 4.8. Фильтры и сортировка
Строка фильтров:
  Тип: [Все ▾] [Фото] [Видео]

  До 999: «340»
  От 1000: «1.2к»

Шрифт: JetBrains Mono, 12px, --text-secondary.

### 4.10. Бесконечная лента (Infinite Scroll)

### 4.11. Админ-панель
Карточка раздела («Мои разделы»):
  Строка 1: #позиция · /slug · название (переименование) · статистика
  Строка 2: кнопка «Треды ▾» · тумблер «Парсить» · «published | unpublished» ·
            «FREE | PREMIUM» · ▲/▼ очередь · удалить
  Статистика: В БД / В S3 / Скачано / Пропущено / В каталоге / Видимых
  (дубли-ссылки не считаются — числа совпадают с сайтом).
  Прогресс парсера: полоса + «парсим тред №X: N/M файлов», «обновлено N с назад»,
  при простое >60 с — красная полоса и «возможно завис».

Треды раздела (аккордеон):
  Чипы: Все · В работе · Парсить · published · PREMIUM · Без настроек
  Поиск по теме/номеру; «в работе» сверху; массовые кнопки:
  Парсить вкл/выкл · Показать/Скрыть · PREMIUM вкл/выкл.
  В строке треда: файлов (files_detected) / скачано (уникальных) / в хранилище /
  видимых / постов / просмотров · тумблеры Парсить / published / PREMIUM
  (при премиум-доске доски тумблер заблокирован с пометкой «унаследовано от доски»).

Тумблеры (переключатели):
  Вкл: фон --accent-secondary, кружок #0A0C0F
  Выкл: фон --bg-tertiary, кружок --text-muted
  Заблокирован (наследование): opacity 60 %, cursor not-allowed

Кнопки действий: малая кнопка (см. 4.3), текст --text-secondary,
  ховер --text-primary; опасные операции (удаление раздела) — --accent-danger.

Глобальные кнопки в шапке админки:
  «Запустить/Остановить парсер» · «Сканировать треды» (в карточке доски) ·
  «Оптимизировать медиа» (бэкфилл, прогресс «осталось N из M») ·
  «Очистить S3» · «Сбросить всё».

## 5. АНИМАЦИИ И ПЕРЕХОДЫ
================================================================================

Длительность: 150–250ms, без плавных затуханий.

Карточки в ленте:
  Появление: fade-in (opacity 0 → 1), длительность 200ms,
             с задержкой 20ms на карточку (stagger-эффект)

Ховер на карточке:
  Изменение рамки: мгновенное (transition 150ms)

Ховер на кнопках:
  Изменение фона/рамки: transition 150ms

Lightbox:
  Открытие: fade-in (opacity 0 → 1), 200ms
  Закрытие: fade-out (opacity 1 → 0), 150ms

Индикатор загрузки:
  Пульсация: opacity 0.3 ↔ 1.0, цикл 1s, ease-in-out

## 7. ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ
================================================================================

  - Время загрузки: LCP не более 2.5s, CLS не более 0.1

Кроссбраузерность:
  - Chrome, Firefox, Safari, Edge (последние 2 версии)
  - Mobile: Android Chrome, iOS Safari
