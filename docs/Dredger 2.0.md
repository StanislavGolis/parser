Dredger 2.0 — концепция развития
Суть
Telegram продаёт. Сайт показывает. Telegram — витрина, канал привлечения и касса. Сайт — закрытая неиндексируемая платформа, куда попадают только оплатившие. Публичного adult-контента нет нигде, кроме закрытого сайта и приватного канала.

1. Роли каналов

Telegram-канал	Витрина: тизеры, новинки, анонсы	Нет (Telegram не индексируется)
Telegram-бот	Оплата, статус, выдача доступа	—
Закрытый сайт	Полный архив, интерфейс, поиск	Убита полностью
Публичная зона (опц.)	Только безопасное (эротика)	Разрешена — SEO-воронка
2. Сайт: закрытая платформа
Что делаем:

Все страницы за авторизацией. Нет сессии → редирект на /login.

robots.txt → Disallow: /.

X-Robots-Tag: noindex, nofollow, noarchive глобально.

Убить: sitemap, JSON-LD, IndexNow, canonical, metadataBase, /t/{id}.

Убрать age gate — он не нужен, сайт закрыт.

Публичными остаются только /login, /auth/*, /healthz.

Что остаётся:

Полный архив: галереи, лайтбокс, поиск, закладки, топ, точка возврата.

Дизайн-система — упростить под массовую аудиторию.

Премиум-гейт: весь контент за подпиской.

Опционально — публичная зона (safe.dredg.ru):

Отдельный поддомен, отдельный SEO.

Только «безопасный» контент — эротика, не-заблокированные разделы.

CTA: «Больше — в Telegram».

Никаких ссылок на закрытый сайт.

3. Telegram: витрина, продажа, доступ
Канал @dredger_news:

1–3 поста в день: 1–2 тизера + ссылка в бота.

Контент — «мягкий» (Telegram банит хардкор).

Цель: завлечь, показать, что архив живой.

Бот @dredger_bot:

/start — приветствие.

/subscribe — тарифы и оплата.

/status — статус подписки.

/link — magic link на сайт.

/help — FAQ.

Поток:

text
Канал → тизер → бот → оплата → magic link → сайт (полный архив)
Авторизация на сайте: только magic link через бота. Пароли не нужны. Telegram ID = аккаунт.

4. Монетизация
Тарифы:

Тариф	Логика
Free	Тизеры в канале, 5 файлов на сайте
Месяц	Полный архив на 30 дней
Год	Скидка ~2 месяца
Навсегда	Окупается за ~2.5 года
Оплата:

Крипта через CryptoBot — работает в adult, не боится блокировок.

Telegram Stars — если канал не забанят за adult.

Ручная выдача — для старта и VIP.

Не используем: Stripe, PayPal, российские эквайринги — adult не пройдёт.

5. Модерация (обязательно)
Без этого проект — уголовный риск, а не бизнес.

Кнопка «пожаловаться» на каждом файле.

Очередь жалоб в админке.

Ручная проверка перед постингом в канал.

Фильтрация по хешам CSAM (если возможно).

Логи: кто, что, когда смотрел.

Быстрое скрытие/удаление по требованию.

Не откладывать. Это не «потом», это «до старта».

6. Юридическая защита
ToS: «мы не авторы, реагируем на жалобы, не храним CSAM».

DMCA-страница + публичный контакт.

Политика конфиденциальности (Telegram ID — ПДн).

Возрастное подтверждение — через ToS бота.

Бэкап-канал Telegram, бэкап-бакет S3, резервный домен.

8. Что остаётся / удаляется / добавляется
Остаётся: парсер, S3, деривативы, премиум-гейт, закладки, топ, поиск, админка, мульти-источники.

Удаляется: SEO-блок (robots/sitemap/JSON-LD/IndexNow), публичные роуты, age gate, онбординг.

Добавляется: Telegram-бот, канал, magic link, подписки, модерация, ToS/DMCA.

9. Экономика (прикидка)
Расходы: $50–100/мес (VPS, S3, домен) + реклама.

Безубыточность: ~20–30 платящих подписчиков.

Ключевой вопрос: сколько людей готовы платить за доступ к архиву 2ch.

10. Главное решение до старта
Почему пользователь пойдёт на сайт, а не останется в Telegram?

Ответ: сайт — полный архив (100 000 файлов, поиск, фильтры), Telegram — витрина (5 тизеров в день). Если весь контент можно смотреть в канале — сайт не нужен. Если в канале только тизеры — сайт нужен.

Рекомендация: сайт — основной продукт. Telegram — воронка. Если пойдёт — добавить премиум-канал как альтернативу сайту.

12. Итог
Модель: Telegram — витрина, продажа и доступ. Сайт — закрытая неиндексируемая платформа с полным архивом за подпиской.

Даёт: снимает юридические риски, решает проблему adult-платежей, использует то, что уже построено.

Требует: убить SEO (больно, но необходимо), закрыть сайт, создать Telegram-инфраструктуру, модерацию, юридическую защиту.

Первые шаги: закрыть сайт → бот и magic link → канал и тизеры → оплата → модерация.
