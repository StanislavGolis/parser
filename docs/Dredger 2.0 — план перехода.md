# Dredger 2.0 — план перехода к модели «Telegram продаёт, сайт показывает»

Документ описывает переход от текущего состояния (публичный индексируемый архив
с премиум-гейтом) к модели из `docs/Dredger 2.0.md`: Telegram — витрина, продажа
и доступ, сайт — закрытая неиндексируемая платформа за подпиской.

---

## 1. Принципы перехода

1. **Не удаляем, а переключаем.** SEO-блок, публичные роуты и age gate остаются в
   коде, но управляются режимом (`SITE_MODE=closed|public`). Причина: удаление
   необратимо, а модель может поменяться; плюс публичная зона (safe-поддомен)
   сможет использовать те же компоненты и разметку.
2. **Сначала снимаем индексацию, потом закрываем обход.** Это не одно действие:
   `noindex` должен быть **виден** роботу, поэтому порядок такой:
   `noindex (X-Robots-Tag)` → 2–4 недели → `robots: Disallow: /` → удаление из
   панелей вебмастера. Если сразу закрыть `Disallow`, страницы останутся в индексе
   надолго (робот не увидит `noindex`).
3. **Модерация — до старта, а не «потом».** Жалобы, очередь проверки, быстрое
   скрытие, запрет автопостинга в канал.
4. **Деньги — без эквайрингов.** Ручная выдача (уже есть) → CryptoBot → Stars как
   эксперимент. Никаких Stripe/PayPal/РФ-эквайрингов.
5. **Один продукт — сайт.** Канал даёт тизеры (5 в день) и ведёт в бота; весь
   архив — только за логином.

## 5. Сворачивание индексации (порядок обязателен)

Сейчас в индексе уже есть страницы (карты отправлены, IndexNow работает). Просто
закрыть `robots` недостаточно — робот перестанет обходить сайт и **не увидит**
`noindex`, а страницы останутся в выдаче месяцами.

1. **Шаг 1 (день 1):** включить `X-Robots-Tag: noindex, nofollow, noarchive` на все
   ответы (Next headers + nginx). Обход **не** закрывать. Отключить cron IndexNow
   и прекратить отправку карт.
2. **Шаг 2 (день 1):** `sitemap.xml` и карты → 404; в GSC/Яндекс.Вебмастере удалить
   карты из списка.
3. **Шаг 3 (неделя 2–4):** проверять «Страницы» в панелях: доля исключённых должна
   расти. Для топ-страниц — «Удаление URL» (GSC) и «Удалить из поиска» (Яндекс).
4. **Шаг 4:** после того как индексируемых страниц почти нет — `robots.txt`:
   `Disallow: /`.
5. **Шаг 5:** включить закрытый режим полностью (редирект на `/login`) — по сути
   фаза 1 в коде готова, включается `SITE_MODE=closed`.

Проверка: `curl -I https://dredg.ru/` → `x-robots-tag: noindex`; `site:dredg.ru`
в поиске не должно расти.

## 6. Риски и меры

| Риск | Мера |
|---|---|
| Telegram банит канал за adult | «Мягкий» контент в канале, бэкап-канал, тизеры без хардкора |
| Telegram банит за CSAM | Модерация до постинга, блок-листы хешей, быстрая реакция, отсутствие автопостинга |
| Оплата криптой сложна для аудитории | Ручная выдача + CryptoBot + (эксперимент) Stars |
| Привычка к бесплатному | Сразу платный архив; Free — 5 файлов в сутки |
| Жалобы правообладателей / удаление контента | DMCA-страница, публичный контакт, скрытие за минуты, аудит действий |
| Отключение S3-бакета | Второй бакет у другого провайдера, репликация важного |
| Блокировка домена | Резервный домен + зеркала, доступ из бота |
| Нагрузка на VPS (уже случалось) | Транскод выключен, лимиты CPU парсеров, LRU-кэш починен, watchdog |

## 7. Метрики успеха

- **Воронка:** показы канала → переходы в бота → `/start` → `/link` → активные на сайте → оплата.
- **Целевые ориентиры:** 20–30 платящих = безубыточность (~$50–100/мес расходов).
- **Retention:** возвраты на сайт за 7/30 дней, использование закладок и точки возврата.
- **Модерация:** среднее время закрытия жалобы, число скрытых файлов.
- **Технические:** load < 2, кэш ≤ 90% бюджета, отсутствие 500.
