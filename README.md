# Dredger — архив // отбор // доступ

Медиа-архив: парсит медиа с разделов форума (2ch), скачивает и архивирует
в объектное хранилище S3 (Timeweb Cloud), каталогизирует и публикует на сайте —
каталог «досок» → треды → файлы с техпанелью, новинки, топ, поиск, аккаунты,
метки («отличный контент») и премиум-подписка.

## Роли

| Роль | Может | Не может |
|---|---|---|
| Аноним | просмотр доступного контента (включая размытые превью премиума), лента, топ, поиск | метки, скачивание, оригиналы, полные премиум-файлы |
| Зарегистрированный | всё как аноним + метки («отличный контент», личный список на `/marks`) + размытые превью премиума | скачивание, оригиналы, полные премиум-файлы |
| Премиум | всё как зарегистрированный + премиум-разделы + скачивание + оригиналы | — |

## Стек

- **Backend**: Python 3.11, FastAPI, SQLAlchemy 2 (async), Alembic, boto3 (S3),
  Pillow + ffmpeg (деривативы), Redis (rate limiting, прогресс парсера).
- **Frontend**: Next.js 14 (App Router), TypeScript, Tailwind; тёмная
  «техническая» дизайн-система.
- **Инфраструктура**: Docker Compose (postgres, redis, migrate, parser, api, web,
  nginx), nginx как точка входа с дисковым кэшем деривативов.

## Быстрый старт

```bash
cp .env.prod.example .env      # заполнить S3_* и ADMIN_TOKEN
docker compose -f docker-compose.prod.yml up -d --build
# сайт:    http://localhost:80
# админка: http://localhost/admin   (ADMIN_TOKEN из .env, хранится в sessionStorage)
```

Разработка без контейнеров:

```bash
# postgres/redis — в Docker; затем:
pip install -r requirements.txt
uvicorn src.api.main:app --reload          # API на :8000
python src/main.py                         # парсер (демон)
cd web && npm install && npm run dev       # фронт на :3000
```

## Что важно знать

- Парсер идемпотентен: повторный проход не размножает записи, уже сохранённые файлы
  пропускаются; коммит БД — после треда и каждые `DB_COMMIT_EVERY_FILES` файлов.
- Премиум закрывает контент целиком (доска/тред): полные версии и **скачивание**
  (оригиналы) — по подписке, публично — только размытое превью `thumb_blur`;
  премиум-ответы не кэшируются. При активной подписке блюр снимается, а вместо
  замка показывается звезда (видно, где премиум-контент).
- «Метка» — единая пользовательская отметка (наш аналог лайка): даёт публичный
  счётчик, влияет на «Популярное», доступна как сортировка «по меткам» и собирает
  личный список «мои метки» (`/marks`; старый адрес `/favorites` редиректит).
  Требует аккаунт; пробел в просмотре файла — быстрая метка.
- В карусели просмотра видео-файлы помечены значком ▶ и длительностью (как на карточках).
- Статистика «файлов / в S3 / видимых» не считает дубли-ссылки — совпадает с сайтом.
- Парсер обходит разделы двухфазно: сначала каталоги всех досок (дёшево, 1 запрос на
  доску), затем докачка по очереди из БД — свежие файлы вперёд, дальше давно не
  сканировавшиеся (LRU); цикл ограничен бюджетом, разделы чередуются. Треды, которые
  выпали из каталога форума, не гасятся с первого промаха, а видны в админке чипами
  «Мёртвые»/«Просроченные»; у удалённого раздела карточка помечается «каталог недоступен».
- Общий образ `parser-backend:local` собирается сервисом `api`:
  `up -d --build parser` код не обновляет (см. `DEPLOY.md` §Диагностика).
