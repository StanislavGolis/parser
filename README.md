# Dredger — медиа-архив

Сервис сбора, обработки и публикации медиаконтента: адаптеры источников →
объектное хранилище (S3) → деривативы (превью, видео) → каталог с поиском и ролями.

## Что внутри

| Слой | Технологии |
|---|---|
| Backend | Python 3.11, FastAPI, SQLAlchemy 2 (async), Alembic, boto3 (S3) |
| Медиа | Pillow + ffmpeg — генерация деривативов, дедупликация, превью |
| Кэш и лимиты | Redis — rate limiting, прогресс парсинга |
| Frontend | Next.js 14 (App Router), TypeScript, Tailwind, тёмная дизайн-система |
| Инфраструктура | Docker Compose (postgres, redis, migrate, parser, api, web, nginx) |

## Архитектурные решения

**Адаптеры источников.** Каждый источник — отдельный класс с общим интерфейсом
`SourceAdapter`: свой контейнер, своё расписание, свой rate limit. Добавление
нового источника не трогает логику каталога.

**Деривативы в S3, метаданные в БД.** Оригиналы не отдаются напрямую: API
генерирует подписанные ссылки с TTL, деривативы кэшируются на диске nginx.

**Миграции отдельным сервисом.** `alembic upgrade head` выполняется сервисом
`migrate`, API ждёт его через `depends_on: condition: service_completed_successfully`.
Рестарт контейнера не меняет схему молча.

**Роли и доступ.** Аноним → зарегистрированный → подписка. Разграничение на
уровне запросов к медиа, оригиналы доступны только с активной подпиской.

**Платежи идемпотентны.** Зачисление идёт по `invoice_id`: повторный вебхук
не зачтёт оплату дважды.

## Быстрый старт

```bash
cp .env.example .env      # заполнить S3_* и ADMIN_TOKEN
docker compose up -d --build
# сайт:    http://localhost:3000
# api:     http://localhost:8000/api/v1/health
```

Разработка без контейнеров:

```bash
pip install -r requirements.txt
uvicorn src.api.main:app --reload    # API на :8000
python src/main.py                   # парсер (демон)
```

## Тесты

```bash
pytest
```

## Структура

```
src/parsers/     адаптеры источников с общим интерфейсом
src/services/    бизнес-логика: каталог, деривативы, платежи, аналитика
src/api/         FastAPI: маршруты, схемы, зависимости
src/tools/       CLI и фоновые задачи (боты, отчёты, импорт)
migrations/      Alembic, 42 миграции
web/             Next.js приложение
```
